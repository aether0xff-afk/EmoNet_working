# EmoNet: 신경조절형 감정 동역학과 잠재 스타일 회귀를 결합한 한국어 감정 응답 생성 파이프라인

## 초록
본 연구는 한국어 감정 대화로부터 응답 내용을 직접 생성하기보다, 먼저 입력 텍스트를 저차원 정서 자극 벡터로 변환하고, 이를 신경조절형 그래프 동역학을 통해 잠재 표현으로 압축한 뒤, 잠재 표현으로부터 스타일 벡터를 회귀하여 최종 응답을 생성하는 다단계 파이프라인 `EmoNet`을 제안한다. 제안 시스템은 `(1)` 텍스트를 4차원 정서 자극 벡터로 인코딩하고, `(2)` 256개 뉴런으로 구성된 그래프에서 활성화, 기억, 억제/흥분, 신경조절, 재배선을 거쳐 dominant branch를 추출하며, `(3)` 이를 64차원 잠재벡터 `z`로 요약하고, `(4)` 로컬 LLM을 이용해 구축한 32차원 스타일 벡터 `s`를 선형 회귀기로 예측한 후, `(5)` 예측 스타일에 맞는 한국어 응답을 생성한다. 로컬 실험 산출물 기준으로 전체 학습용 `z` 데이터는 51,628개 대화 샘플, 감정 라벨은 60종으로 구성되었고, 균형 샘플링된 500개 LLM subset 중 200개 샘플에 대해 스타일 라벨링을 수행하였다. 이 중 190개 샘플이 일관성 임계값을 통과했으며, 평균 consistency L1은 0.0998이었다. 다만 간이 hold-out 평가에서 현재 선형 `z -> s` 회귀기는 mean baseline을 아직 넘지 못했으며, 종단 응답 생성 검증 또한 LLM 서버 연결 실패로 인해 최종 단계 평가가 완료되지 않았다. 현재 스타일 공간이 지나치게 온건하고 협조적인 응답 쪽으로 수렴하는 구조적 한계도 관찰되었다. 그럼에도 본 파이프라인은 감정 동역학, 스타일 중간표현, 응답 생성을 명시적으로 분리한 점에서 해석 가능한 감정 응답 생성 연구의 기반으로 활용될 수 있다.

## 1. 서론
감정 대화 생성은 단순한 정답 생성 문제가 아니라, 입력의 정서적 결을 어떤 중간 표현으로 보존하고 어떤 말투로 표면화할 것인가의 문제다. 기존 접근은 입력 텍스트로부터 직접 응답을 생성하거나, 감정 라벨을 보조 신호로 사용해 디코더를 조건부 제어하는 방식이 많다. 그러나 이런 방식은 감정의 내부 동학과 응답 표면 스타일이 하나의 블랙박스 안에서 뒤섞이는 문제가 있다.

본 프로젝트의 목표는 감정 상태를 몇 개의 명시적 단계로 분해하는 것이다. 먼저 텍스트를 정서 자극 벡터로 바꾸고, 이 자극이 가상의 신경 그래프에서 어떻게 퍼지고 수렴하는지를 모사한 뒤, 최종적으로 남는 dominant branch를 잠재벡터로 요약한다. 이후 이 잠재벡터로부터 직접 응답을 생성하지 않고, 32차원 스타일 벡터를 예측하여 응답 표면의 말투와 리듬을 제어한다. 이 구조는 다음 세 가지 점에서 의미가 있다.

- 감정 처리 과정을 `text -> stim -> graph dynamics -> z -> s -> response`로 분리해 각 단계의 실패 원인을 추적할 수 있다.
- 최종 응답 이전에 `z`와 `s`라는 중간 표현을 두어 해석 가능성을 높인다.
- 스타일 라벨을 직접 수작업으로 설계하지 않고, 로컬 LLM을 이용해 약지도 형태의 `(z, s)` 데이터셋을 구축할 수 있다.

다만 현재 버전은 여전히 과하게 온화하고 협조적인 응답으로 수렴하는 경향이 있으며, 이는 데이터 구성, 스타일 축 설계, 생성 프롬프트의 상호작용에서 비롯된 것으로 보인다. 본 초안은 현재 구현과 산출물을 기준으로 시스템을 정리하고, 무엇이 구현되었고 무엇이 아직 검증되지 않았는지를 논문 형식으로 명확히 기술하는 데 목적이 있다.

## 2. 시스템 개요

### 2.1 전체 파이프라인
EmoNet의 전체 파이프라인은 다음과 같다.

1. 한국어 감정 대화 입력을 하나의 텍스트 시퀀스로 정규화한다.
2. 자극 인코더가 입력을 4차원 `stim_vec = [dopamine, serotonin, norepinephrine, melatonin]`으로 변환한다.
3. 256개 뉴런으로 구성된 그래프가 여러 tick 동안 활성화되며 branch log를 생성한다.
4. 생존 branch만 남긴 뒤 top-k 경로를 통합해 dominant branch를 만든다.
5. dominant branch를 64차원 잠재벡터 `z`로 압축한다.
6. `(z, s)` 약지도 데이터로 학습한 선형 회귀기에서 32차원 스타일 벡터 `s_pred`를 예측한다.
7. `s_pred`를 스타일 프롬프트로 변환해 로컬 LLM으로 최종 한국어 응답을 생성한다.

이 구조는 감정 상태를 곧바로 언어로 매핑하지 않고, 중간 동역학과 중간 스타일 공간을 거치게 함으로써 각 단계의 의미를 분리한다.

### 2.2 텍스트-자극 인코더
자극 인코더는 텍스트를 4차원 연속값 자극으로 변환한다. 구현상 이 단계는 TF-IDF 기반 Ridge 회귀를 사용하며, 문자 n-gram 또는 단어 n-gram 표현 중 벤치마크 CSV에서 더 나은 구성을 선택한다. 학습 목표 자체는 외부 정답 자극 벡터가 아니라, 말뭉치의 `y` 값과 텍스트 힌트 사전을 결합해 구성한 proxy target이다.

구체적으로 긍정성, 성취, 주도성, 안정, 위협, 긴박, 피로, 휴식과 관련된 한영 키워드 집합을 기반으로 dopamine, serotonin, norepinephrine, melatonin 값을 조합한다. 따라서 이 인코더는 순수한 감정 분류기라기보다, 텍스트의 정서적 분위기를 간이 신경조절 신호로 투영하는 프런트엔드에 가깝다.

### 2.3 신경 그래프 동역학
그래프는 256개 뉴런으로 구성되며, 억제성 115개, 흥분성 115개, 조절성 26개로 나뉜다. 각 뉴런은 활성도 `K`, 자극 벡터, threshold, remem, refractory 상태, dropout 여부, in/out edge, memory list를 가진다.

한 tick에서 뉴런은 다음 과정을 거친다.

- 이전 tick에서 전달된 pending signal을 평균해 입력 강도로 받는다.
- 자극 벡터의 일부 차원은 `K`를 올리고, 일부 차원은 `K`를 내린다.
- threshold를 넘은 뉴런만 활성 후보가 된다.
- 활성 후보는 자신의 memory와 현재 자극의 cosine similarity를 통해 자극과 `K`를 조정한다.
- 뉴런 유형에 따라 억제성/흥분성 효과가 자극 분포를 평균 쪽 혹은 극단 쪽으로 이동시킨다.
- 조절성 뉴런은 dropout, global threshold shift, global remem shift를 야기한다.
- 활성 뉴런은 outgoing edge로 신호를 전파하고, serotonin/dopamine 관련 값에 의해 edge pruning 또는 rewiring이 일어난다.

이후 branch log에서 마지막 생존 경로를 기준으로 pruned branch를 만들고, top-k 경로를 점수 가중 평균해 dominant branch를 구성한다.

### 2.4 Branch-to-z 인코딩
dominant branch의 각 step은 `stim_vec(4) + K + tick_norm`을 이어붙인 6차원 피처로 표현된다. 현재 기본 설정에서는 torch transformer 대신 NumPy 기반 요약 인코더를 사용한다. 이 인코더는 branch의 평균, 표준편차, 최소/최대, 처음/끝 값, 변화량, 기울기를 요약한 뒤 무작위 선형사상과 `tanh`를 거쳐 64차원 `z`를 생성한다.

즉, 현재 `z`는 end-to-end로 학습된 잠재표현이 아니라, dominant branch 요약 특징에 대한 고정 투영 표현이다. 그 대신 구현 단순성과 안정성이 높다.

### 2.5 잠재 스타일 회귀
`z`에서 곧바로 응답을 생성하지 않고, 먼저 32차원 스타일 벡터 `s`를 예측한다. 스타일 축은 verbosity, directness, warmth, politeness, calmness, tension, softness, sharpness, seriousness 등 말투와 표현 특성 중심으로 구성된다.

`z -> s` 회귀는 선형 Ridge 회귀로 구현되어 있으며, 입력 `z`를 정규화한 뒤 평균 중심화된 스타일 타깃을 예측한다. 이 설계는 복잡한 비선형 예측보다는, 현재 구축 가능한 데이터 규모에서 안정적인 기본선을 확보하려는 선택으로 해석할 수 있다.

### 2.6 스타일 기반 응답 생성
최종 응답 생성 시에는 입력 텍스트와 함께 style tags, macro style summary, style vector 전체를 프롬프트에 넣고 로컬 LLM을 호출한다. 이 단계는 내용 생성보다 말투 제어를 우선하는 구조이며, 프롬프트는 응답 길이, 평문 형식, 한국어 문장 수 등을 제한한다.

## 3. 데이터셋 및 `(z, s)` 구축 절차

### 3.1 원시 데이터
프로젝트 산출물 기준 학습용 `z` 데이터 파일 `outputs/z/out_z_training.csv`에는 총 51,628개 샘플이 포함되어 있으며, 감정 라벨은 60종이다. 상위 빈도 라벨은 `E37`, `E13`, `E24`, `E27`, `E31` 등으로 관찰된다. 각 행에는 원문 텍스트, 메타데이터, 64차원 `z`, 4차원 자극값, dominant branch 길이가 저장된다.

### 3.2 균형 subset 추출
LLM 라벨링 비용을 줄이기 위해 `outputs/llm/llm_subset.csv`를 별도로 구축했다. 이 파일은 500개 샘플로 구성되며, 60개 라벨 전반을 비교적 고르게 포함하도록 균형 샘플링되었다.

### 3.3 로컬 LLM 기반 스타일 라벨링
subset 샘플에 대해 로컬 LLM이 먼저 예시 응답을 생성하고, 이어서 동일 응답을 다시 읽으며 32개 스타일 축을 block 단위로 평가한다. 이때 두 종류의 벡터를 저장한다.

- `s`: 생성된 응답이 가져야 하는 목표 스타일
- `s_hat`: 실제 생성된 응답을 다시 평가한 스타일

프로젝트 구현에서는 block size 8 기준으로 32축을 4개 block으로 쪼개어 JSON 형식의 안정성을 높였다. 또한 각 축은 0.00, 0.25, 0.50, 0.75, 1.00의 5단계 값으로 양자화된다.

### 3.4 일관성 필터링
`consistency_l1 = mean(abs(s - s_hat))`를 기준으로 LLM 자기일관성이 높은 샘플만 유지한다. 현재 산출물 기준 결과는 다음과 같다.

| 파일 | 총 샘플 수 | keep 샘플 수 | keep 비율 | mean consistency L1 | median consistency L1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `llm_subset_labeled_50_ollama.csv` | 50 | 48 | 96.0% | 0.0444 | 0.0438 |
| `llm_subset_labeled_200_ollama.csv` | 200 | 190 | 95.0% | 0.0998 | 0.0938 |

반면 `llm_subset_labeled_50.csv`는 `keep_sample`이 모두 false로 남아 있어 현재 학습용 주 결과로 사용하기 어렵다. 따라서 현 단계에서는 `*_ollama.csv` 계열 결과가 보다 신뢰 가능한 라벨 소스로 보인다.

## 4. 실험 설정

### 4.1 구현
구현은 Python 기반 CLI 형태로 제공되며, 주요 명령은 다음과 같다.

- `export-z`: 원시 데이터에서 `z`와 자극값을 추출
- `build-llm-subset`: 균형 subset 구성
- `label-local`: 로컬 LLM으로 `(s, s_hat)` 라벨링
- `fit-zs-regressor`: `z -> s` 회귀기 학습
- `predict-s`: 대규모 `z` 파일에 `s_pred` 부착
- `generate-response`: 단일 입력에 대한 스타일 조건부 응답 생성
- `e2e-check`: 전체 파이프라인 검증

### 4.2 로컬 생성 모델
산출물과 기본 인자 설정 기준으로, 응답 생성 및 스타일 라벨링에는 Ollama 호환 OpenAI API 엔드포인트를 통해 `gpt-oss:20b` 또는 유사 로컬 모델 구성이 사용되었다. 단, 현재 저장된 검증 로그에는 서버 연결 실패 사례도 포함되어 있어 모든 결과가 동일한 온라인 상태에서 산출되었다고 보기는 어렵다.

### 4.3 평가 관점
현 버전에서 명시적으로 구현된 평가는 다음 세 단계에 집중된다.

1. `text -> z` 단계의 형상과 수치 안정성 검증
2. `z -> s_pred` 단계의 범위 및 차원 검증
3. `s_pred + input_text -> llm_response` 단계의 응답 생성 가능 여부 검증

여기에 더해 `(s, s_hat)` 간 consistency를 샘플 품질 필터로 사용한다.

## 5. 결과

### 5.1 단계별 파이프라인 결과
저장된 `e2e_check_report.json` 기준, `text -> z` 단계와 `z -> s_pred` 단계는 정상 통과했다. 예시 입력 "지금 너무 예민하고 피곤해."에 대해 관찰된 값은 다음과 같다.

- `stim_vec` 차원: 4
- `dominant_branch_len`: 1
- `z` 차원: 64
- `s_pred` 차원: 32

그러나 최종 `LLM response` 단계는 로컬 서버 미가동으로 실패했다. 따라서 현 시점에서 end-to-end 검증은 "표현 추출과 스타일 예측까지는 통과, 최종 생성은 인프라 상태에 의존"하는 상황으로 요약할 수 있다.

### 5.2 정성적 예시
저장된 단일 응답 예시에서는 입력 "요즘 너무 지치고 예민해."에 대해 다음과 같은 스타일 추정이 이루어졌다.

- 높은 warmth
- 높은 cooperativeness
- 높은 politeness
- 높은 calmness
- 낮은 tension
- 낮은 sharpness

그 결과 생성된 응답은 위로, 제안, 상담형 종결을 포함한 매우 완화된 문체를 보였다. 이는 현재 시스템이 감정의 날것보다는 정돈되고 친절한 말투로 수렴하는 경향을 정성적으로 보여준다.

### 5.3 현재 결과의 해석
현 버전 결과는 다음 두 가지를 동시에 시사한다.

첫째, `z -> s` 스타일 예측 체계와 LLM 자기일관성 필터는 최소한 데이터 구축 도구로는 동작한다. 200개 샘플 중 190개가 임계값을 통과했다는 점은 적어도 현재 스타일 축 공간 안에서는 라벨링 품질이 완전히 붕괴하지 않았음을 뜻한다.

둘째, 그 스타일 공간 자체가 지나치게 온건한 응답을 선호할 가능성이 높다. keep 샘플 평균 기준으로 cooperativeness 0.9197, calmness 0.9184, softness 0.9605, positivity 0.9092인 반면, sharpness 0.0382, tension 0.0961, dominance 0.1066으로 나타난다. style summary 예시에서도 warmth, cooperativeness, calmness가 높고 tension, sharpness가 낮게 예측되는 패턴이 반복되며, 실제 응답도 같은 방향으로 표면화된다.

셋째, 현재 선형 `z -> s` 회귀기의 일반화 성능은 아직 충분하지 않다. 5개 seed hold-out split에서 평균 검증 MAE는 0.1422였고, 동일 split에서의 mean baseline MAE는 0.1371로 더 낮았다. 따라서 현재 결과는 "잠재표현이 스타일을 잘 예측한다"기보다 "스타일 공간이 평균값 주변에 강하게 몰려 있다"는 쪽에 더 가깝다.

## 6. 논의

### 6.1 장점
본 시스템의 가장 큰 장점은 감정 응답 생성 문제를 하나의 거대한 생성 모델에 맡기지 않고, 해석 가능한 중간 단계들로 분해했다는 점이다. `stim_vec`, branch log, dominant branch, `z`, `s_pred`는 각각 독립적으로 저장되고 검증될 수 있으므로, 어떤 단계에서 표현이 붕괴하는지 추적하기 쉽다.

또한 로컬 LLM을 이용해 `(z, s)` 데이터셋을 자동 구축하는 방식은 수작업 스타일 주석 비용을 낮춘다. block-wise JSON 평가와 consistency filtering 역시 현실적인 엔지니어링 절충안이다.

### 6.2 한계
현재 프로젝트에는 몇 가지 구조적 한계가 있다.

첫째, 입력 구성 자체가 발화자와 상담자 문장을 함께 이어붙이는 방식이라, 감정 강도보다 상담형 톤이 더 잘 보존될 가능성이 있다.

둘째, 32개 스타일 축은 말투 특성 중심이며, 분노, 원망, 체념, 자기혐오, 비꼼, 감정 폭발 같은 거친 정서축이 부족하다. 따라서 모델은 날것의 감정을 직접 표현하기보다, 온화함/예의/협조성 축에서 해를 찾게 된다.

셋째, 응답 생성 프롬프트는 style tags와 macro summary를 함께 넣는데, 이 요약 과정이 평균화된 말투를 강화할 수 있다.

넷째, branch-to-z 인코더는 현재 학습형 transformer가 아니라 고정 NumPy 투영에 가깝다. 이 때문에 `z`가 실제 의미 있는 감정 잠재공간인지에 대한 근거는 아직 약하다.

다섯째, 현재 로그 기준으로 최종 응답 단계의 안정적 자동 평가는 완료되지 않았다. 서버 연결 실패는 모델 품질과 별개의 인프라 이슈이지만, 논문 결과의 완결성을 떨어뜨린다.

### 6.3 왜 응답이 과하게 온화해지는가
현재 구현과 산출물을 종합하면, 과도한 온화함은 세 층위에서 발생한다.

- 데이터 층위: 사용자 발화와 상담자 발화가 같은 입력에 섞인다.
- 표현 층위: style axis가 raw affect보다 polite conversational style에 치우쳐 있다.
- 생성 층위: 프롬프트가 "자연스럽게", "평문", "직접 답한다"는 지시와 함께 warmth/cooperativeness 중심 summary를 다시 주입한다.

즉 문제는 단순히 LLM 하나의 성향이 아니라, 데이터와 중간표현과 프롬프트가 함께 만든 유도 편향으로 보는 편이 타당하다.

## 7. 향후 연구
다음 단계의 개선 방향은 비교적 명확하다.

1. 입력에서 화자 역할을 분리하고, 사용자 감정 발화와 상담자 반응을 별도 채널로 인코딩한다.
2. style axis에 hostility, resentment, despair, sarcasm, emotional volatility, profanity tendency 같은 raw affect 축을 추가한다.
3. macro summary 없이 raw style vector만으로 생성하는 설정과 비교한다.
4. 현재의 고정 branch encoder 대신 학습 가능한 sequence encoder를 도입해 `z`의 표현력을 높인다.
5. 최종 응답에 대해 인간 평가 혹은 별도 스타일 판정기를 붙여 `s_pred`와 실제 응답 스타일 간의 정합성을 평가한다.
6. 친절함 중심 응답과 날것 감정 응답 사이의 trade-off를 명시적으로 제어하는 multi-objective 설정을 도입한다.

## 8. 결론
EmoNet은 한국어 감정 대화에 대해 자극 벡터, 신경 그래프 동역학, 잠재 스타일 회귀, LLM 표면화 단계를 분리한 실험적 파이프라인이다. 현재 산출물 기준으로 `text -> z -> s_pred`까지의 처리 경로는 작동하며, 51,628개 규모의 `z` 데이터와 190개 keep 샘플을 포함한 `(z, s)` 약지도 데이터 구축도 가능함을 보였다. 반면 최종 응답은 과도하게 온화하고 상담형으로 수렴하는 경향이 있으며, 이는 모델 하나의 문제가 아니라 데이터 구성, 스타일 축 설계, 프롬프트 설계가 함께 만든 결과로 해석된다. 따라서 본 시스템의 핵심 기여는 완성된 감정 응답 모델 그 자체라기보다, 감정 동역학과 응답 스타일을 분리해 실험할 수 있는 해석 가능한 연구 골격을 제공한다는 데 있다.
