# EmoNet: 감정 동역학 기반 중간표현과 스타일 회귀를 이용한 한국어 응답 생성 파이프라인

## 초록
감정 대화 생성은 입력 의미를 보존하는 것만으로 충분하지 않다. 모델은 입력이 유발하는 정서 상태를 내부적으로 어떻게 구성할지, 그리고 그 상태를 어떤 말투와 표현 강도로 외부에 드러낼지를 함께 결정해야 한다. 그러나 기존의 end-to-end 감정 대화 생성은 감정 표현과 표면 스타일을 하나의 생성기 내부에 함께 묶는 경우가 많아, 어느 단계에서 어떤 편향이 발생하는지 분리해 분석하기 어렵다. 본 연구는 한국어 감정 응답 생성을 `text -> stim_vec -> graph dynamics -> dominant branch -> z -> s -> response`의 다단계 파이프라인으로 분해한 `EmoNet`을 제안한다. 제안 시스템은 입력 텍스트를 4차원 정서 자극 벡터로 투영한 뒤, 256개 뉴런으로 구성된 그래프 동역학을 통해 branch를 형성하고, 이를 64차원 잠재벡터 `z`로 요약한다. 이후 로컬 LLM으로 구축한 약지도 `(z, s)` 데이터셋을 이용해 32차원 스타일 벡터 `s`를 회귀하고, 예측된 스타일을 조건으로 최종 응답을 생성한다. 현재 산출물 기준 `z` 데이터는 51,628개 샘플과 60개 감정 라벨을 포함하며, 균형 추출된 500개 subset 중 200개 샘플에 대해 스타일 라벨링을 수행했다. 이 가운데 190개 샘플이 consistency filtering을 통과했고, 평균 consistency L1은 0.0998이었다. End-to-end 점검에서는 `text -> z -> s -> response` 경로가 정상 동작했으나, `z -> s` 선형 회귀기는 평균 baseline보다 낮은 MAE를 보이지 못했다. 또한 생성 응답은 warmth, calmness, cooperativeness, softness 축으로 강하게 편향되었고 sharpness, tension, dominance는 낮게 나타났다. 이 결과는 현재 파이프라인의 핵심 가치가 최종 성능 향상보다는 감정 표현과 응답 스타일을 명시적으로 분해하고, 각 단계의 구조적 병목을 진단할 수 있는 분석 프레임워크에 있음을 보여준다.

## 1. 서론
감정 응답 생성은 단순한 조건부 텍스트 생성 문제가 아니다. 동일한 의미를 전달하더라도, 화자의 정서 상태와 응답자의 태도에 따라 표현의 온도, 거리감, 직설성, 안정감은 크게 달라진다. 따라서 감정 대화 시스템은 무엇을 말할지뿐 아니라 어떤 정서적 경로를 거쳐 어떤 스타일로 말할지를 함께 다뤄야 한다.

기존 연구는 주로 두 방향으로 전개되어 왔다. 첫째는 입력 텍스트를 바로 응답으로 매핑하는 end-to-end 생성 방식이다. 둘째는 감정 라벨, control token, prompt attribute를 보조 입력으로 사용해 생성기를 조건부 제어하는 방식이다. 이들 접근은 실제 사용에서 강력할 수 있지만, 감정 상태 표현과 표면 스타일 형성이 하나의 모델 내부에서 함께 일어나므로 다음과 같은 한계가 있다.

- 감정 표현이 어떤 중간 상태를 거쳐 형성되는지 추적하기 어렵다.
- 특정 스타일의 응답이 왜 생성되었는지 설명하기 어렵다.
- 감정 상태와 스타일을 독립적으로 조절하거나 진단하기 어렵다.

본 연구는 이 문제를 해결하기 위해 감정 응답 생성을 다음과 같은 중간표현 기반 파이프라인으로 분해한다.

```text
text -> stim_vec -> graph dynamics -> dominant branch -> z -> s -> response
```

이 구조의 목적은 단순히 생성 단계를 늘리는 데 있지 않다. 오히려 감정 표현의 형성과 응답 스타일의 표면화를 분리하여, 어느 단계가 실제 병목인지 분석 가능하게 만드는 데 있다. 이를 위해 입력 텍스트를 먼저 저차원 자극 벡터로 변환하고, 그래프 동역학을 통해 시간적 경로를 형성한 뒤, 그 결과를 잠재벡터 `z`와 스타일 벡터 `s`로 나누어 다룬다. 최종 응답은 `s`를 명시적으로 조건으로 받는 로컬 LLM이 생성한다.

현재 실험 결과는 두 가지 사실을 동시에 보여준다. 첫째, 파이프라인 자체는 end-to-end로 작동하며 `stim_vec`, `dominant branch`, `z`, `s_pred`, `response`를 각 단계별 산출물로 분리해 기록할 수 있다. 둘째, 현재 스타일 공간과 데이터 구성은 지나치게 온건하고 협조적인 응답으로 수렴하는 편향을 낳고 있으며, `z -> s` 회귀 성능 또한 mean baseline을 넘지 못한다. 즉, 본 연구는 성능 우위를 주장하는 논문이라기보다, 감정 응답 생성 문제를 분해하고 구조적 병목을 진단하기 위한 분석 중심 프레임워크에 가깝다.

본 연구의 기여는 다음과 같다.

1. 한국어 감정 응답 생성을 감정 동역학, 잠재표현, 스타일 회귀, 표면화 단계로 분해한 모듈형 파이프라인을 제안한다.
2. 4차원 자극 벡터와 그래프 기반 동역학을 통해 감정 상태의 흐름을 중간 구조로 표현하는 방법을 구현한다.
3. 로컬 LLM을 활용해 32차원 스타일 벡터를 자동 라벨링하고, `(z, s)` 약지도 데이터셋을 구축하는 절차를 제안한다.
4. 현재 시스템의 핵심 병목이 회귀기 자체보다 데이터 구성, 스타일 축 설계, 프롬프트 평균화에 있음을 실험적으로 분석한다.

## 2. 관련 연구

### 2.1 감정 대화 생성
감정 대화 생성은 공감적 응답 생성과 정서 조건부 대화 모델을 중심으로 발전해 왔다. 대표적인 접근은 encoder-decoder 혹은 instruction-tuned LLM이 입력 대화와 감정 조건을 함께 받아 응답을 생성하는 방식이다. 이러한 방법은 실용적이지만, 감정 정보를 discrete label이나 간단한 prompt attribute로 축약하는 경우가 많아 감정의 연속적 변화나 내부 상태 전이를 직접 다루기 어렵다.

### 2.2 스타일 제어 텍스트 생성
스타일 제어 생성에서는 politeness, formality, sentiment, toxicity, persona 등 다양한 속성을 조건으로 텍스트를 생성하는 연구가 축적되었다. 여기서는 control token, prefix tuning, attribute classifier guidance, prompt-based control이 널리 사용된다. 다만 많은 접근은 스타일을 생성기의 입력 조건으로만 사용하고, 스타일 자체를 별도의 예측 대상 혹은 독립적인 중간표현으로 다루지 않는다.

### 2.3 잠재공간 기반 controllable generation
잠재변수 기반 생성 모델과 latent space steering은 생성 과정을 직접 제어하기 위한 유력한 틀을 제공한다. 그러나 일반적인 latent space는 해석 가능성이 낮고, 감정 상태와 표현 스타일이 한 공간 안에 혼재되는 경우가 많다. 본 연구는 latent vector `z`를 곧바로 생성기로 전달하기보다, `z -> s` 회귀를 한 단계 더 두어 잠재표현과 스타일 표면화 사이를 분리한다는 점에서 차별화된다.

### 2.4 neuro-inspired 표현 모델
생물학적 비유를 차용한 인공신경망 연구는 지속적으로 존재해 왔으나, 감정 대화의 중간표현을 그래프 동역학과 branch 구조로 기록하는 시도는 상대적으로 드물다. 본 연구는 생리학적 정확성을 주장하지 않는다. 대신 dopamine, serotonin, norepinephrine, melatonin을 입력의 정서적 특성을 요약하는 저차원 proxy signal로 사용하고, 이를 기반으로 감정 상태의 전개를 구조적으로 모사한다.

## 3. 연구 문제와 포지셔닝
본 연구는 다음 세 가지 질문에 답하고자 한다.

1. 감정 응답 생성을 하나의 생성기 대신 모듈형 중간표현 파이프라인으로 분해할 수 있는가.
2. 로컬 LLM을 이용한 약지도 스타일 라벨링이 `z -> s` 학습을 위한 최소한의 데이터 구축 절차로 기능하는가.
3. 파이프라인을 분해했을 때, 현재 시스템의 병목이 어느 단계에 존재하는지 더 명확히 진단할 수 있는가.

이 질문 설정은 본 연구의 포지션을 분명히 한다. EmoNet은 현재 시점에서 SOTA 성능을 목표로 한 완성형 생성 모델이 아니다. 오히려 감정 표현과 스타일 제어를 분리해 분석 가능한 연구 골격을 제공하고, 실제 병목이 표현 학습보다 데이터와 스타일 설계에 더 크게 놓여 있음을 보여주는 분석 중심 구조 논문이다.

## 4. 방법

### 4.1 전체 파이프라인
EmoNet의 전체 흐름은 다음과 같다.

1. 입력 한국어 대화를 정규화하여 하나의 텍스트 시퀀스로 구성한다.
2. 자극 인코더가 입력을 4차원 `stim_vec`으로 변환한다.
3. 그래프 동역학이 여러 tick 동안 활성화되며 branch log를 생성한다.
4. branch score를 기준으로 dominant branch를 추출한다.
5. dominant branch를 64차원 잠재벡터 `z`로 요약한다.
6. 약지도 `(z, s)` 데이터로 학습한 선형 회귀기가 32차원 스타일 벡터 `s`를 예측한다.
7. 로컬 LLM이 `input_text`와 `s`를 함께 받아 최종 응답을 생성한다.

핵심은 감정 상태를 즉시 언어로 변환하지 않는다는 점이다. EmoNet은 감정적 자극, 동역학적 경로, 잠재표현, 스타일 표면화 단계를 분리하여 각 단계의 실패를 독립적으로 진단할 수 있게 한다.

### 4.2 텍스트에서 자극 벡터로의 투영
입력 텍스트는 다음 네 축으로 구성된 자극 벡터로 투영된다.

- dopamine: 보상감, 동기, 접근 성향
- serotonin: 안정감, 만족, 정서적 평형
- norepinephrine: 긴장, 각성, 위협 민감성
- melatonin: 피로, 휴식, 둔화 성향

구현상 이 단계는 TF-IDF 기반 Ridge 회귀를 사용한다. 학습 타깃은 실제 생리 신호가 아니라, 감정 말뭉치와 정서 키워드 사전을 결합해 만든 proxy target이다. 따라서 본 단계는 생리학적 예측기가 아니라, 텍스트의 정서적 분위기를 저차원 연속 공간으로 투영하는 전처리 계층으로 이해해야 한다.

### 4.3 신경 그래프 동역학
그래프는 총 256개 뉴런으로 구성되며, 115개의 inhibitory node, 115개의 excitatory node, 26개의 modulatory node를 포함한다. 각 뉴런은 활성도 `K`, threshold, memory, refractory state, dropout state, in/out edge를 가진다.

각 tick에서 그래프는 다음 순서로 업데이트된다.

- 이전 tick에서 전달된 입력 신호를 집계한다.
- 자극 벡터와 누적 상태를 이용해 `K`를 갱신한다.
- memory와 현재 자극의 유사도를 기반으로 자극과 `K`를 조정한다.
- inhibitory/excitatory/modulatory 유형에 따라 국소 혹은 전역 조절을 적용한다.
- 활성 노드가 edge를 통해 신호를 전파한다.
- pruning과 rewiring을 통해 그래프 구조를 업데이트한다.

이 절차는 생물학적 사실의 모사가 아니라, 감정 상태가 정적인 라벨이 아니라 시간에 따라 확산, 수렴, 억제되는 구조라는 관점을 구현한 것이다.

### 4.4 Branch 추출과 dominant branch 구성
각 tick의 활성 노드와 발화 edge는 branch log로 기록된다. 이후 마지막까지 생존한 경로를 중심으로 branch를 복원하고, 점수 기반으로 상위 경로를 통합하여 dominant branch를 만든다. 이 dominant branch는 감정 상태가 그래프 안에서 어떤 경로를 따라 수렴했는지 요약한 중간 구조로 해석할 수 있다.

### 4.5 Branch에서 잠재벡터 `z`로의 인코딩
dominant branch의 각 step은 `stim_vec(4) + K + tick_norm`으로 이루어진 6차원 피처로 표현된다. 현재 기본 설정은 학습형 transformer가 아니라 통계 요약 기반 인코더이다. 구체적으로 각 축에 대해 평균, 표준편차, 최소, 최대, 시작값, 종료값, 변화량, 기울기를 계산하고, 이 요약값을 고정 선형사상과 `tanh`를 통해 64차원 벡터 `z`로 투영한다.

현재 `z`는 end-to-end 학습된 latent code가 아니라 branch 요약 특징에 대한 고정 투영 표현이다. 이는 표현력 측면에서는 한계가 있지만, 구현이 단순하고 각 차원이 어떤 통계에서 유래했는지 추적 가능하다는 장점이 있다.

### 4.6 잠재벡터에서 스타일 벡터 `s`로의 회귀
스타일 벡터 `s`는 총 32차원으로 구성되며 verbosity, directness, warmth, politeness, cooperativeness, calmness, softness, sharpness, tension, seriousness 등 응답 말투와 표현 강도를 기술한다. `z -> s` 매핑은 Ridge regression으로 구현되며, 입력 `z`를 정규화한 뒤 연속형 스타일 벡터를 예측한다.

이 단계의 목적은 스타일 제어를 응답 생성기의 내부 상태에 암묵적으로 맡기지 않고, 관찰 가능한 중간 변수로 끌어내는 데 있다. 즉, EmoNet은 `z`를 내용과 정서 흐름의 요약으로, `s`를 표면 스타일의 요약으로 분리해 다룬다.

### 4.7 스타일 조건부 응답 생성
최종 응답 생성 시 로컬 LLM은 다음 정보를 함께 입력받는다.

- 원문 입력 텍스트
- style vector
- style tags
- macro style summary

LLM은 스타일을 설명하는 것이 아니라, 해당 스타일을 실제 문장 형태로 표면화하는 역할을 수행한다. 따라서 이 단계는 내용 생성 자체보다 스타일 반영 여부를 확인하는 제어 계층에 가깝다.

### 4.8 로컬 LLM 기반 `(z, s)` 약지도 데이터 구축
스타일 라벨은 수작업 주석 대신 로컬 LLM을 활용해 구축했다. 먼저 subset 샘플에 대해 LLM이 응답 초안을 생성하고, 이어서 같은 응답을 다시 읽으며 32개 스타일 축에 대한 평가값을 산출한다. 이때 두 종류의 벡터를 저장한다.

- `s`: 목표 스타일 벡터
- `s_hat`: 실제 생성 응답을 다시 평가한 벡터

32개 축은 block size 8 기준으로 나누어 평가하여 JSON 형식 안정성을 높였고, 각 축은 5단계 값으로 양자화하였다. 이후 `mean(abs(s - s_hat))`를 consistency로 정의해 자기일관성이 낮은 샘플을 제거한다.

## 5. 데이터와 실험 설정

### 5.1 데이터
학습용 `z` 데이터는 총 51,628개 샘플로 구성되며, 감정 라벨은 60종이다. 각 샘플에는 정규화된 대화 텍스트, 메타데이터, 64차원 `z`, 4차원 자극값, dominant branch 길이가 포함된다. LLM 기반 스타일 라벨링 비용을 줄이기 위해 별도로 500개 균형 subset을 추출했다.

### 5.2 스타일 라벨링 subset
500개 subset 중 현재 주 결과는 200개 샘플에 대한 로컬 LLM 라벨링 결과를 사용한다. 이 가운데 190개 샘플이 keep threshold를 통과했으며, keep rate는 95.0%이다. 평균 consistency L1은 0.0998, 중앙값은 0.0938이었다. 추가로 50개 샘플 실험에서는 평균 consistency L1이 0.0444로 더 낮게 나타났으나, 본 논문에서는 규모가 더 큰 200개 결과를 중심으로 보고한다.

### 5.3 구현 환경
전체 시스템은 Python CLI로 구현되었고, 주요 명령은 `export-z`, `build-llm-subset`, `label-local`, `fit-zs-regressor`, `predict-s`, `generate-response`, `e2e-check`로 구성된다. 스타일 라벨링과 최종 응답 생성은 Ollama 호환 OpenAI-compatible 엔드포인트를 통해 수행되었으며, 저장된 성공 로그 기준 모델 이름은 `gpt-oss:20b`이다.

### 5.4 평가 관점
현 단계 평가는 다음 네 수준에서 수행했다.

1. `text -> z` 경로의 차원 및 수치 안정성
2. `(s, s_hat)` consistency를 통한 약지도 스타일 라벨 품질 점검
3. `z -> s` 회귀기의 hold-out MAE 평가
4. `s_pred + input_text -> response`의 end-to-end 실행 가능성 및 정성 분석

본 논문은 아직 사람 평가나 대규모 자동 평가를 포함하지 않는다. 따라서 결과는 완성형 생성 품질 평가라기보다 구조 진단 관점에서 해석해야 한다.

## 6. 결과

### 6.1 파이프라인 동작 확인
저장된 end-to-end 점검 로그 기준으로 `text -> z`, `z -> s_pred`, `s_pred + text -> response`의 모든 단계는 정상 통과했다. 예시 입력 "난 니가 싫어."에 대해 자극 벡터는 4차원, dominant branch 길이는 1, 잠재벡터 `z`는 64차원, 예측 스타일 벡터 `s_pred`는 32차원으로 생성되었고, 최종 응답도 비어 있지 않은 한국어 문장으로 반환되었다. 이는 제안 파이프라인이 구현 수준에서 end-to-end로 연결되어 있음을 보여준다.

### 6.2 스타일 라벨링 consistency
200개 라벨링 샘플 중 190개가 consistency filtering을 통과했다. keep rate가 95% 수준이라는 것은 최소한 현재 정의한 스타일 공간 안에서는 LLM 기반 자기평가가 완전히 무작위적이지 않으며, 약지도 데이터 구축 도구로는 작동하고 있음을 시사한다. 다만 이 결과는 라벨의 객관적 타당성을 보장하는 것이 아니라, 동일 모델 혹은 동일 프롬프트 체계 안에서의 자기일관성이 높다는 뜻에 가깝다.

### 6.3 `z -> s` 회귀 성능
190개 keep 샘플을 사용해 5개 seed hold-out split으로 평가한 결과, 선형 회귀기의 평균 검증 MAE는 0.1422였고 동일 분할에서의 mean baseline MAE는 0.1371이었다. 즉, 현재 회귀기는 baseline보다 평균적으로 0.0051 높은 오차를 보였다. 이는 현재 잠재벡터 `z`가 스타일 정보를 충분히 담지 못하거나, 스타일 타깃 공간이 평균 근처로 강하게 수렴해 단순 baseline이 이미 강력하다는 것을 시사한다.

### 6.4 스타일 분포 편향
keep 샘플 평균 스타일을 보면 cooperativeness 0.9197, calmness 0.9184, softness 0.9605, positivity 0.9092, warmth 0.7776으로 매우 높게 나타난 반면, sharpness 0.0382, tension 0.0961, dominance 0.1066은 매우 낮았다. 이는 현재 스타일 공간과 라벨링 절차가 날것의 감정 표현보다 협조적이고 상담형인 말투를 강하게 선호하고 있음을 보여준다.

### 6.5 정성적 예시
입력 "요즘 너무 지치고 예민해."에 대해 예측된 스타일은 높은 warmth, politeness, cooperativeness, calmness, softness와 낮은 sharpness, tension을 보였다. 실제 생성 응답 역시 위로, 제안, 완화된 문장 종결을 중심으로 구성되었다. 반면 입력 "난 니가 싫어."에 대해서도 응답은 사과와 대화 유지를 제안하는 협조적 톤으로 생성되었다. 이는 파이프라인이 부정적 입력을 받아도 현재 스타일 공간이 공격성이나 긴장을 충분히 표면화하지 못하고 있음을 잘 보여준다.

## 7. 분석

### 7.1 현재 병목은 어디에 있는가
현재 결과를 종합하면, EmoNet의 병목은 단일 회귀기 하나에만 있지 않다. 파이프라인은 구현 수준에서 작동하지만, 생성 결과가 지나치게 온건한 방향으로 수렴하고 있고 `z -> s` 예측도 baseline을 넘지 못한다. 따라서 현재 문제는 모델이 전혀 동작하지 않는 것이 아니라, 어떤 스타일 공간과 데이터 구성을 통해 학습하고 있는지가 부적절하다는 쪽에 가깝다.

### 7.2 데이터 구성의 영향
현재 입력은 사용자 발화와 상담자 발화를 하나의 텍스트로 이어붙인다. 이 구성은 사용자의 날것의 정서보다 상담자 측의 정돈된 어조를 더 강하게 반영할 수 있다. 결과적으로 자극 인코더와 이후 단계는 부정적 감정 상태를 읽더라도, 전체 시퀀스 차원에서는 이미 완화된 대화 맥락을 함께 받아들이게 된다.

### 7.3 스타일 공간 설계의 영향
현재 32개 스타일 축은 주로 politeness, softness, calmness, structure, cooperativeness 같은 대화 매너 축에 치우쳐 있다. 반면 hostility, resentment, disgust, contempt, emotional volatility, sarcasm, profanity tendency와 같은 거친 감정 축은 부재하거나 약하다. 이 경우 스타일 회귀와 생성 단계는 자연스럽게 "어떻게 부드럽게 말할 것인가"의 문제로 수렴한다.

### 7.4 프롬프트 평균화의 영향
최종 응답 생성은 style tags와 macro style summary를 함께 사용한다. 이 요약은 높은 warmth와 낮은 tension 같은 평균화된 속성을 재차 강조하며, 벡터의 세부 변동보다 중앙 경향을 강화할 수 있다. 따라서 현재 생성 편향은 LLM의 일반적 친절함뿐 아니라, 프롬프트 자체가 평균적인 상담형 스타일을 재주입하는 구조와도 연결된다.

### 7.5 해석 가능한 실패라는 점의 의미
중요한 점은, 이러한 병목이 파이프라인 분해 덕분에 비교적 명확히 드러났다는 사실이다. 만약 동일 문제를 하나의 end-to-end 생성기 안에서만 관찰했다면, 편향의 원인이 데이터인지 프롬프트인지 latent representation인지 구분하기 어려웠을 것이다. EmoNet은 현재 성능 면에서 강하지 않더라도, 적어도 편향의 위치를 진단 가능한 형태로 외부화했다는 점에서 연구적 의미가 있다.

## 8. 논의

### 8.1 장점
EmoNet의 가장 큰 장점은 감정 응답 생성을 중간표현 중심으로 분해했다는 점이다. `stim_vec`, branch log, dominant branch, `z`, `s_pred`, 최종 response가 모두 독립 산출물로 남기 때문에 단계별 오류 분석이 가능하다. 또한 로컬 LLM을 활용한 `(z, s)` 약지도 구축 절차는 수작업 스타일 주석 비용을 줄이는 현실적인 방법을 제공한다.

### 8.2 한계
현재 연구에는 분명한 한계가 있다. 첫째, branch-to-`z` 인코더는 학습형이 아닌 고정 통계 투영이라 표현력이 제한적이다. 둘째, `z -> s` 회귀 성능이 baseline을 넘지 못해 잠재표현의 예측 효용이 아직 입증되지 않았다. 셋째, 스타일 라벨은 인간 주석이 아니라 동일 계열 LLM 기반 자기평가에 크게 의존한다. 넷째, 최종 생성 품질에 대한 인간 평가와 비교 baseline이 아직 없다. 따라서 현재 단계의 결론은 효과성 입증보다 구조적 관찰에 무게를 두어야 한다.

## 9. 향후 연구
향후 연구에서는 다음 네 방향이 중요하다.

1. 입력에서 화자 역할을 분리하여 사용자 감정과 상담자 반응을 별도 채널로 인코딩한다.
2. hostility, sarcasm, resentment, despair, volatility 등 raw affect 축을 스타일 공간에 추가한다.
3. 고정 branch encoder 대신 학습 가능한 sequence encoder를 도입해 `z`의 표현력을 높인다.
4. direct prompting, stim-only prompting, full style prompting을 포함한 baseline과 사람 평가를 추가한다.

이 개선이 수행되면 EmoNet은 단순한 구조 제안에서 나아가, 실제로 어떤 중간표현이 스타일 제어와 감정 표현 보존에 기여하는지 더 엄밀하게 평가할 수 있다.

## 10. 결론
본 연구는 한국어 감정 응답 생성을 `text -> stim_vec -> graph dynamics -> dominant branch -> z -> s -> response`로 분해한 모듈형 파이프라인 `EmoNet`을 제안했다. 현재 결과는 파이프라인의 구현 가능성과 분석 가능성을 보여주지만, 동시에 스타일 공간의 강한 온건화 편향과 `z -> s` 회귀의 낮은 일반화 성능도 드러낸다. 따라서 EmoNet의 현재 가치는 최종 성능 우위 자체보다, 감정 동역학과 응답 스타일을 분리 가능한 연구 객체로 재구성하고 그 병목을 구조적으로 진단할 수 있게 했다는 점에 있다.
