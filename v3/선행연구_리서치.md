# 선행연구 리서치 메모

## 정리 방향
선행 연구는 "무엇을 따라갔는가"보다 "기존 방식이 어디서 멈추고, 그래서 왜 EmoNet 같은 구조가 필요한가"를 보여주는 방향으로 정리하는 편이 좋다. 아래는 본문에 직접 넣기 좋게 네 갈래로 나눈 정리다.

## 1. 공감형 감정 대화 생성

### MoEL
- 논문: Lin et al., 2019, *MoEL: Mixture of Empathetic Listeners*
- 핵심: 사용자 감정을 분포 형태로 추정하고, 감정별 listener를 mixture 방식으로 결합해 공감 응답을 생성한다.
- 의의: 공감 응답 생성에서 감정 조건을 해석 가능한 listener 구조와 연결했다.
- 한계: 감정을 내부 상태 전개라기보다 response selection 조건으로 다룬다.
- EmoNet과 연결: 감정이 라벨 이후 어떻게 전개되는지까지 설명하려면 listener 혼합보다 내부 경로 모델링이 필요하다는 논리로 이어갈 수 있다.

### EmpDG
- 논문: Li et al., 2020, *EmpDG: Multi-resolution Interactive Empathetic Dialogue Generation*
- 핵심: 대화 수준과 토큰 수준의 감정을 함께 반영해 보다 세밀한 공감 응답을 만든다.
- 의의: 감정을 단일 coarse label로 축약하지 않고 multi-resolution으로 확장했다.
- 한계: 감정의 미세한 표현은 다루지만, 여전히 생성기 내부 경로는 블랙박스다.
- EmoNet과 연결: EmoNet은 감정의 "해상도"뿐 아니라 감정이 내부에서 이동하는 "경로"를 남긴다는 점에서 차별화된다.

### SEEK
- 논문: Wang et al., 2022, *Empathetic Dialogue Generation via Sensitive Emotion Recognition and Sensible Knowledge Selection*
- 핵심: 기존 연구가 감정을 정적 변수로 다룬다고 비판하고, emotion flow를 더 민감하게 추적하는 serial encoding과 emotion-knowledge interaction을 제안했다.
- 의의: 감정이 발화 간에 동적으로 바뀐다는 문제의식을 분명히 제시했다.
- 한계: emotion flow를 다루지만, 그것이 최종 스타일 제어 공간으로 어떻게 압축되는지까지는 이어지지 않는다.
- EmoNet과 연결: EmoNet은 emotion flow 문제의식을 branch history와 dominant branch로 더 명시적인 구조로 옮긴다고 설명할 수 있다.

### NEC
- 논문: Huangfu et al., 2025, *Non-Emotion-Centric Empathetic Dialogue Generation*
- 핵심: 세밀한 감정 인식 오류가 공감 응답 생성에 연쇄 오류를 낳는다고 분석하고, 감정 중심 접근 자체를 재검토한다.
- 의의: fine-grained emotion recognition의 한계를 정면으로 비판한다.
- 한계: 감정을 배제하거나 약화할 때 설명 가능성이 더 좋아지는 것은 아니다.
- EmoNet과 연결: EmoNet은 감정을 라벨 예측으로만 다루지 말고, 자극-경로-스타일의 연쇄 구조로 재설계해야 한다는 방향으로 답한다.

## 2. 감정 흐름과 그래프 기반 구조

### DialogueGCN
- 논문: Ghosal et al., 2019, *DialogueGCN: A Graph Convolutional Neural Network for Emotion Recognition in Conversation*
- 핵심: 대화 참여자 간 self/inter-speaker dependency를 그래프로 모델링해 감정 인식 성능을 높였다.
- 의의: 대화 감정을 순차 모델만이 아니라 그래프 전파 문제로 다룬 초기 대표 사례다.
- 한계: 목표는 감정 분류이며, 생성 단계나 스타일 제어까지 연결되지는 않는다.
- EmoNet과 연결: EmoNet은 그래프를 분류기 대신 생성 직전 감정 상태의 동역학 코어로 사용한다는 점이 다르다.

### CTSM
- 논문: Wang et al., 2024, *CTSM: Combining Trait and State Emotions for Empathetic Response Model*
- 핵심: trait emotion과 state emotion을 함께 모델링해야 공감 응답이 더 좋아진다고 주장한다.
- 의의: 정적 성향과 동적 상태를 분리해야 한다는 심리학적 관점을 응답 생성에 접목했다.
- 한계: 여전히 embedding 정렬과 decoder 학습 중심이며, 내부 감정 경로를 외부화하지는 않는다.
- EmoNet과 연결: EmoNet도 장기 성향과 단기 반응의 분리를 염두에 두되, 이를 branch 경쟁과 동역학 구조까지 확장한다.

## 3. 제어 가능한 생성

### CTRL
- 논문: Keskar et al., 2019, *CTRL: A Conditional Transformer Language Model for Controllable Generation*
- 핵심: control code로 스타일, 내용, 작업 유형을 제어한다.
- 의의: 큰 언어모델을 재학습 없이 명시적 코드로 제어할 수 있음을 보여줬다.
- 한계: control code는 제어 신호이지, 감정 상태 형성과정의 모델이 아니다.
- EmoNet과 연결: EmoNet은 control signal을 바로 주입하는 대신, 내부 감정 동역학이 먼저 제어 신호를 생성하게 한다.

### PPLM
- 논문: Dathathri et al., 2020, *Plug and Play Language Models*
- 핵심: attribute classifier gradient로 pretrained LM의 hidden activation을 조정한다.
- 의의: 모델 재학습 없이 속성 제어를 가능하게 한 대표적 plug-and-play 방식이다.
- 한계: 제어의 중심이 decoding-time intervention이며, 감정 상태의 구조적 표현은 없다.
- EmoNet과 연결: EmoNet은 디코딩 시점의 intervention보다 사전 단계의 감정 상태 구성에 더 무게를 둔다.

### FUDGE
- 논문: Yang and Klein, 2021, *FUDGE: Controlled Text Generation With Future Discriminators*
- 핵심: partial sequence에 대한 attribute predictor를 이용해 미래 속성을 만족하도록 확률을 보정한다.
- 의의: 여러 속성을 조합해 유연하게 제어할 수 있다.
- 한계: 여전히 출력 decoding 조절 문제에 초점이 있다.
- EmoNet과 연결: EmoNet은 감정 제어를 decoding policy가 아니라 internal state construction의 문제로 본다.

## 4. 잠재공간과 스타일 분리

### Neural Stylistic Response Generation with Disentangled Latent Variables
- 논문: Zhu et al., 2021
- 핵심: latent space에서 content와 style을 분리해 스타일 강도를 높이면서 내용 적합성을 유지한다.
- 의의: 응답 생성에서 style-content disentanglement의 효용을 보여준다.
- 한계: style latent는 있지만 감정 상태가 어떻게 형성되었는지 설명하지는 않는다.
- EmoNet과 연결: EmoNet은 `z`와 `s`를 분리하는 아이디어를 계승하되, `z` 이전에 branch history를 둔다.

### MIRACLE
- 논문: Lu et al., 2023
- 핵심: 여러 personal attribute를 잠재공간에서 조합 가능하게 제어한다.
- 의의: 다중 속성 제어와 fine-grained controllability를 강화했다.
- 한계: persona와 스타일 조합에는 강하지만, 감정 동역학적 전개를 다루는 구조는 아니다.
- EmoNet과 연결: EmoNet은 다중 속성 제어보다 감정 상태가 스타일로 번역되기 전 내부 궤적을 더 중시한다.

## 5. 본문에 바로 넣을 수 있는 정리 문단
기존 연구는 공감형 응답 생성, 그래프 기반 감정 모델링, 제어 가능한 텍스트 생성, 잠재공간 기반 스타일 분리에서 각각 중요한 진전을 이루었다. 그러나 대부분의 접근은 감정을 라벨, 속성, 임베딩, 또는 출력 제어 신호로 다루며, 감정 자극이 내부 상태의 전개를 거쳐 응답 스타일로 표면화되는 전 과정을 하나의 해석 가능한 연쇄 구조로 제시하지는 못했다. 이에 비해 EmoNet은 자극 벡터, 군집형 감정 동역학, dominant branch, 잠재 감정 표현 `z`, 스타일 벡터 `s`를 순차적으로 연결함으로써 감정을 단순 조건이 아니라 추적 가능한 내부 상태 변화로 다룬다는 점에서 기존 연구와 구별된다.
