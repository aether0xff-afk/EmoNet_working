# EmoNet 논문 작성용 청사진

## 제목 후보
1. EmoNet: 신경조절형 감정 동역학과 잠재 스타일 회귀를 결합한 한국어 응답 생성 프레임워크
2. EmoNet: 감정 상태 궤적과 스타일 표면화를 분리한 한국어 응답 생성 모델
3. EmoNet: 뇌 영감형 감정 동역학과 스타일 제어를 이용한 한국어 LLM 응답 생성

## 먼저 고쳐 쓰면 좋은 표현
논문에서는 "인간의 뇌를 모사했다"라고 단정하기보다 "인간의 정서 조절 메커니즘에서 영감을 받은 neuro-inspired 구조"라고 쓰는 편이 안전하다. 실제 뇌의 생리학을 재현했다는 주장보다, 정서 자극의 누적, 확산, 억제, 기억, 재구성 과정을 계산 구조로 설계했다는 식으로 표현해야 설득력이 높다.

## 초록
본 연구는 대규모 언어모델의 감정 처리가 주로 라벨 분류, 프롬프트 조건 부여, 또는 표면적 말투 제어 수준에 머무른다는 한계를 해결하기 위해, 입력 자극으로부터 내부 감정 상태의 전개를 거쳐 응답 스타일을 생성하는 다단계 프레임워크 `EmoNet`을 제안한다. 제안 모델은 입력 텍스트 `x`를 정서 자극 벡터로 인코딩한 뒤, 구조적 클러스터를 갖는 감정 동역학 신경망 `\mathcal{N}(\mathcal{C})` 안에서 자극을 확산시키고, 그 과정에서 형성된 branch history를 잠재 감정 표현 `z`로 압축한다. 이후 잠재 표현으로부터 스타일 벡터 `s`를 회귀하고, 이를 프롬프트 제어 신호로 변환하여 최종 LLM 응답 `y`를 생성한다. 이 구조는 감정을 단순히 분류하는 것이 아니라, 감정이 형성되고 조절되는 내부 경로를 추적 가능한 중간표현으로 외부화한다는 점에서 기존 end-to-end 감정 생성 모델과 구별된다. 연구는 세 단계로 진행된다. 첫째, Encoder가 입력 자극을 안정적으로 추출하는지 검증한다. 둘째, 뉴런 기능의 추가 및 제거, 잠재벡터 크기 변화 등 구조적 ablation을 통해 어떤 구성요소가 실제 감정 제어 성능에 기여하는지 분석한다. 셋째, 최종 응답의 감정 적합성, 스타일 일치성, 자연성, 제어 가능성을 자동 평가와 인간 평가로 점검하여 상용화 가능성을 검토한다. 본 연구의 의의는 감정 응답 생성을 하나의 블랙박스 생성 문제로 다루는 대신, 감정 자극, 내부 동역학, 잠재 표현, 스타일 표면화 단계를 분리함으로써 감정 제어의 해석 가능성과 실험 가능성을 함께 높인 데 있다.

## 선행 연구
관련 연구는 [[선행연구]] 문서에서 별도로 정리했다. 본문에서는 다음 네 흐름만 짧게 요약하면 된다.

1. 공감형 대화 생성 연구는 감정 인식과 응답 생성을 결합했지만, 감정을 주로 라벨이나 condition으로만 사용했다.
2. controllable generation 연구는 속성 제어에는 강하지만, 감정 내부 상태의 형성과 변화 자체를 모델링하지 않는다.
3. latent-style 분리 연구는 내용과 스타일을 구분하지만, 감정 동역학과 연결되는 내부 경로는 제공하지 않는다.
4. 본 연구는 자극 벡터, 클러스터 기반 감정 동역학, dominant branch, 잠재 감정 `z`, 스타일 벡터 `s`를 하나의 연쇄 구조로 묶는다는 점에서 차별화된다.

## 연구 문제 설정
아래 문단은 거의 그대로 써도 된다.

기존의 감정 조건부 언어모델은 감정을 주로 분류 가능한 범주나 프롬프트 속성으로 다루어 왔다. 그러나 실제 감정 반응은 단일 라벨의 선택이 아니라, 외부 자극이 내부 상태를 변화시키고 그 변화가 다시 표현 양식에 영향을 미치는 연속적 과정에 가깝다. 따라서 단순한 감정 분류 또는 감정 토큰 주입만으로는 "감정을 이해하고 조절하여 표현한다"는 수준의 설명력을 확보하기 어렵다. 특히 기존 접근은 모델 내부에서 감정 상태가 어떻게 형성되고, 어떤 중간 표현을 거쳐, 어떤 스타일로 표면화되는지를 추적하기 어렵다는 한계를 가진다. 본 연구는 이 문제를 해결하기 위해, 감정 자극의 인코딩, 내부 신경 동역학, 잠재 감정 압축, 스타일 회귀, 응답 생성으로 이어지는 분리형 구조를 설계하고자 한다.

문제 정의는 세 문장으로 압축해도 좋다.

1. 기존 LLM은 감정을 "느끼는 상태의 전개"보다 "감정 라벨의 판별"에 가깝게 다룬다.
2. 기존 감정 제어 방식은 내부 감정 경로를 설명하지 못해 해석 가능성과 제어 가능성이 낮다.
3. 따라서 감정 자극에서 응답 스타일로 이어지는 중간 상태를 명시적으로 모델링할 새로운 구조가 필요하다.

## 연구 목표
연구 목표는 연구 문제와 바로 대응되게 적는 것이 좋다.

1. 입력 자극으로부터 내부 감정 상태의 전개를 생성하는 neuro-inspired 감정 동역학 신경망을 설계한다.
2. 설계한 신경망이 자극을 잠재 감정 표현 `z`와 스타일 표현 `s`로 안정적으로 가공할 수 있는지 실험적으로 검증한다.
3. 최종 응답이 기존 방식보다 감정 적합성, 스타일 제어 가능성, 자연성 측면에서 개선되는지 평가한다.
4. 응답 지연, 구조 단순화 가능성, 프롬프트 호환성 등을 기준으로 실제 서비스 적용 가능성을 점검한다.

## 시스템의 구조와 각 구조에 대한 설명
수식은 유지하되 이름을 조금 더 세련되게 붙이는 편이 좋다.

```text
x -> Perceptual Affective Encoder -> stim vec
  -> Clustered Neuro-Affective Dynamics Core
  -> Dominant Branch History H_branch
  -> Latent Affect Distiller E_H
  -> z
  -> Tone Realizer R_tone
  -> s
  -> Prompt Composer G_prompt
  -> LLM
  -> y
```

수식 버전은 다음처럼 제시하면 된다.

```math
x \rightarrow Encoder(x) \rightarrow stim\ vec \rightarrow \mathcal{N}(\mathcal{C})
\rightarrow H_{branch} \rightarrow E_H \rightarrow z \rightarrow R_{tone}(z)
\rightarrow s \rightarrow G_{prompt} \rightarrow LLM \rightarrow y
```

### 1. Perceptual Affective Encoder
이 모듈은 입력 텍스트를 단순 의미 벡터가 아니라 감정 반응을 유발할 수 있는 자극 표현으로 바꾸는 단계다. 핵심은 텍스트를 바로 응답으로 넘기지 않고, 모델 내부에서 먼저 "무엇이 감정적 자극으로 작용했는가"를 추상화한다는 데 있다. 논문에서는 이 계층을 감정 처리의 시작점으로 설명하면 된다. 즉, 입력 문장의 의미, 어조, 긴장도, 공격성, 위로 필요성, 피로감 등을 정서 자극으로 투영하고, 이후 신경망이 이 신호를 받아 내부 상태를 변화시킨다고 서술하면 된다.

### 2. Clustered Neuro-Affective Dynamics Core
이 단계는 논문의 핵심이다. 자극 벡터는 구조적 클러스터를 가진 신경망에 주입되고, 각 뉴런은 흥분, 억제, 조절, 기억의 역할을 나누어 수행한다. 감정은 여기서 하나의 라벨이 아니라 네트워크 내부에서 퍼지고 억제되고 지속되는 동적 상태로 해석된다. 특히 클러스터 구조를 두는 이유는 감정 반응이 완전히 균일한 전역 확산이 아니라, 특정 기능군 내부에서 더 강하게 결속되고 일부 경로만 다른 군으로 전달되는 구조를 갖기 때문이다. 다시 말해, 클러스터는 감정 처리의 기능적 국소성과 재구성 가능성을 동시에 제공한다.

### 3. Dominant Branch History
자극이 신경망 안을 통과하면 여러 뉴런 경로가 동시에 생기지만, 실제 응답을 결정하는 것은 그중 상대적으로 더 강하고 더 오래 유지된 경로다. 이 연구에서는 그 경로를 dominant branch라고 정의하고, branch history `H_branch`를 감정 상태 궤적의 기록 장치로 사용한다. 이 장치는 단순 평균 활성도보다 훨씬 풍부한 정보를 제공한다. 어느 뉴런 집합이 먼저 반응했는지, 어떤 경로가 억제되었는지, 어떤 경로가 끝까지 살아남았는지를 시각화할 수 있기 때문이다.

### 4. Latent Affect Distiller
`E_H`는 branch history를 저차원 잠재 표현 `z`로 압축하는 모듈이다. 이 단계가 필요한 이유는 내부 동역학의 전체 기록을 그대로 LLM에 전달하면 구조가 너무 무겁고 해석도 어렵기 때문이다. 따라서 논문에서는 `z`를 "응답 직전의 요약된 감정 상태"로 정의하면 좋다. 중요한 포인트는 `z`가 단순 감정 라벨이 아니라, 자극-동역학-경로 선택 과정을 거친 후 남은 잠재 상태라는 점이다.

### 5. Tone Realizer
`R_tone`은 잠재 감정 `z`를 언어 표면으로 직접 바꾸지 않고, 먼저 스타일 벡터 `s`로 회귀하는 단계다. 이 분리는 매우 중요하다. 감정 상태와 표면 말투는 관련은 있지만 동일하지 않기 때문이다. 예를 들어 동일한 긴장 상태라도 어떤 응답은 차갑고 짧게 표현될 수 있고, 다른 응답은 격식 있고 억제된 문장으로 표현될 수 있다. 따라서 `s`는 감정 표현의 표면 양식을 제어하는 중간 레이어로 설명하면 된다.

### 6. Prompt Composer and LLM Surface Realizer
마지막 단계에서는 스타일 벡터 `s`를 프롬프트 조건으로 변환하고, LLM이 그 조건을 만족하는 응답 `y`를 생성한다. 논문에서는 이 부분을 "LLM이 감정을 계산하는 것이 아니라, EmoNet이 계산한 감정 상태와 스타일을 언어 표면으로 실현하는 역할을 맡는다"라고 정리하면 구조가 매우 선명해진다. 즉, 감정 생성의 중심은 LLM이 아니라 EmoNet 내부 동역학에 있다.

## 연구 방법
연구 방법은 "Episode" 형식으로 쓰면 스토리텔링이 잘 된다.

### Episode 1. 자극 인코더는 감정적 입력을 분리해 낼 수 있는가
이 실험은 입력 텍스트가 실제로 유의미한 자극 벡터로 변환되는지 검증한다. 자세한 실험 설계는 [[Encoder Testing]]에 정리했다.

### Episode 2. 어떤 뉴런 기능이 감정 동역학에 실제로 기여하는가
이 실험은 흥분, 억제, 조절, 기억, rewiring 기능을 하나씩 제거하거나 추가하면서 dominant branch의 변화와 최종 응답 차이를 비교한다. 자세한 실험 설계는 [[뉴런의 기능 추가 및 제거에 따른 결과 실험]]에 정리했다.

### Episode 3. 잠재벡터 `z`의 크기는 어느 수준이 적절한가
`z`의 크기를 32, 64, 128 등으로 바꾸어 정보 보존과 제어 가능성 사이의 균형점을 찾는다. 자세한 실험 설계는 [[z의 크기 변화 실험]]에 정리했다.

### Episode 4. 기존 방법보다 실제로 나아졌는가
여기서는 반드시 baseline을 둬야 한다.

1. Direct LLM: 입력 텍스트만 넣고 바로 응답 생성
2. Emotion Label Prompting: 감정 라벨만 프롬프트에 넣는 방식
3. Stim-only Control: 자극 벡터만 이용하는 단순 제어
4. Full EmoNet: 전체 파이프라인

이 비교는 자동 평가와 인간 평가를 둘 다 쓰는 편이 좋다.

### 추천 metric
1. Emotion Appropriateness: 응답이 입력의 감정 맥락에 얼마나 잘 맞는가
2. Style Consistency: 목표 스타일 벡터 `s`와 실제 응답에서 추정한 스타일 사이의 거리
3. Naturalness: 사람이 읽었을 때 어색하지 않은가
4. Controllability: 원하는 감정 톤 변화가 실제 응답에 반영되는가
5. Diversity: 같은 입력에 대해 구조 변화가 다른 응답을 유도하는가
6. Latency: 실제 사용 가능 수준의 응답 시간을 보이는가

### 추천 human evaluation 문항
각 문항을 1점에서 5점 사이 Likert scale로 받으면 된다.

1. 이 응답은 입력 화자의 감정 상태를 잘 이해하고 있다.
2. 이 응답은 감정의 강도와 방향을 자연스럽게 반영하고 있다.
3. 이 응답의 말투는 의도한 스타일과 일치한다.
4. 이 응답은 자연스럽고 사람답다.
5. 이 응답은 기존 baseline보다 더 설득력 있는 감정 반응처럼 느껴진다.

## 연구 결과
결과 파트는 단순 수치 나열이 아니라 "왜 이 구조를 최종 채택했는가"로 연결해야 한다.

### 1. Encoder 결과 해석
자극 인코더가 입력의 감정 강도와 방향을 안정적으로 분리했다면, 이후 모든 구조가 의미를 가진다. 반대로 여기서 분리가 안 되면 뒤쪽 동역학 성능이 좋아 보여도 구조적 해석력이 약해진다.

### 2. 뉴런 기능 ablation 해석
이 부분은 논문의 가장 강한 장점이 될 수 있다. 예를 들어 억제성 뉴런을 제거했을 때 branch 수가 과도하게 증가하거나 응답이 지나치게 불안정해졌다면, 억제 구조가 감정 폭주를 막는 데 필요하다는 해석을 제시할 수 있다. 조절성 뉴런 제거 시 스타일 다양성이 줄었다면, 이 기능이 감정의 표현 양식을 조율하는 데 기여한다고 연결하면 된다.

### 3. `z` 크기 변화 해석
`z`가 너무 작으면 감정 상태를 충분히 담지 못하고, 너무 크면 잡음과 과적합이 늘어난다. 따라서 최종 결과에서는 단순 최고 점수보다 "성능, 안정성, 계산 비용의 균형"을 이유로 특정 차원을 채택했다고 쓰는 것이 좋다.

### 4. 분포 시각화 해석
가능하면 다음 그림을 넣는 것이 좋다.

1. `z` 공간의 UMAP 또는 t-SNE 분포
2. `z`에서 `s`로 투영된 축별 분포
3. dominant branch 길이 분포
4. 뉴런 클러스터 활성 heatmap
5. baseline 대비 human score bar chart

특히 "`어떤 z에 대해 어떤 s가 나왔는지`"는 산점도, density plot, 또는 heatmap으로 보여주는 것이 좋다.

그림은 많이 넣는 편이 맞다. 다만 각 그림의 역할이 분명해야 한다.

종류: 시스템 개요도

전달 메시지: EmoNet은 단일 생성기가 아니라 중간표현을 거치는 다단계 구조다.

전달 메시지: 감정 상태는 구조적 네트워크 내부에서 생성되고 조정된다.

전달 메시지: 뉴런 하나도 단순 합산기가 아니라 기억과 조절을 가지는 계산 단위다.

### Figure 4. branch 형성과 dominant branch 선택
종류: 시간축 경로 그림

전달 메시지: 잠재 표현과 스타일 표현이 완전히 임의적이지 않고 구조를 가진다.

종류: 실험 프로토콜 플로우

전달 메시지: 연구가 단순 구현 보고가 아니라 단계적 검증 절차를 갖는다.

## 결론
결론은 다음 구조로 쓰면 된다.

첫째, 본 연구는 감정 응답 생성을 자극 인코딩, 내부 감정 동역학, 잠재 감정 압축, 스타일 회귀, LLM 표면화로 분리한 EmoNet 구조를 제안하였다. 둘째, 실험을 통해 어떤 뉴런 기능과 잠재표현 구성이 실제 감정 제어와 스타일 반영에 기여하는지 분석하였다. 셋째, 이를 통해 기존의 감정 라벨 기반 제어보다 해석 가능하고 조절 가능한 감정 응답 생성의 가능성을 확인하였다. 마지막으로, 상용화를 위해서는 latency 최적화, 인간 평가 확장, 스타일 공간의 정교화가 후속 연구로 필요함을 보였다.
