# 뉴런의 기능 추가 및 제거에 따른 결과 실험

## 실험 질문
흥분, 억제, 조절, 기억, rewiring 기능은 감정 동역학과 최종 응답 품질에 각각 어떤 기여를 하는가.

## 실험 목적
이 실험은 EmoNet이 단순히 복잡한 구조를 쌓은 것이 아니라, 각 기능이 실제로 필요한 이유가 있음을 보여주기 위한 것이다. 논문에서 가장 설득력 있는 ablation 파트가 될 수 있다.

## ablation 설정 예시
1. Full model
2. Without inhibitory neurons
3. Without modulatory neurons
4. Without memory update
5. Without rewiring
6. Without branch pruning

## 측정 항목
1. dominant branch length
2. branch count per sample
3. activation stability
4. cluster utilization entropy
5. style consistency
6. human-rated emotion appropriateness
7. response diversity

## 예상되는 해석 방향
### 억제성 뉴런 제거
branch가 지나치게 많아지거나 응답이 과도하게 요동친다면, 억제 구조가 감정 폭주를 제어하는 핵심 요소라고 해석할 수 있다.

### 조절성 뉴런 제거
스타일 다양성 또는 제어 가능성이 줄어든다면, 조절 구조가 감정 상태를 언어 표면으로 변환하는 과정에서 세밀한 톤 조절에 기여한다고 볼 수 있다.

### 기억 제거
같은 감정군 안에서도 응답의 맥락 지속성이 떨어진다면, 기억 메커니즘이 감정의 잔존성과 맥락 연속성을 담당한다고 해석할 수 있다.

### rewiring 제거
시간이 지날수록 특정 클러스터에 과도하게 편중되거나 branch가 경직된다면, rewiring은 감정 동역학의 적응성과 균형을 유지하는 기능으로 설명할 수 있다.

## 본문에 바로 넣을 수 있는 문장
각 뉴런 기능의 기여를 검증하기 위해 기능 제거 기반 ablation 실험을 수행하였다. 그 결과 억제, 조절, 기억, 재배선 메커니즘은 모두 서로 다른 방식으로 감정 동역학의 안정성과 응답 스타일의 제어 가능성에 기여하였다. 특히 일부 기능을 제거했을 때 dominant branch의 길이와 분산, cluster 활용 패턴, 최종 응답의 감정 적합성에서 뚜렷한 저하가 관찰되었다면, 이는 제안 구조가 단순한 장식이 아니라 기능적 필요성을 가진 설계임을 보여준다.
